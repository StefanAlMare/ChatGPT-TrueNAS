# ChatGPT Drop 0.9.0-rc14 V8 — First Public Prerelease

**Product:** ChatGPT Drop (Apple/macOS client) · **Project:** ChatGPT-TrueNAS  
**Platform:** macOS Intel x86_64 · **Build:** 14 · **Status:** PRERELEASE / testing only

This is the **latest RC14 V8 artifact**, not RC13. No older RC candidates are part of this public release.

## What it does

- Finder Quick Action: **Send to ChatGPT Drop**.
- Preserves Finder originals; transfers frozen batches over SMB to owner-controlled NAS with remote BYTES/SHA-256 verification and retry state.
- Prefers LAN/private-network SMB; can use private embedded Tailscale/tsnet when direct SMB is unreachable.
- Clipboard BATCH/PATH/BYTES/SHA256 handover for a compatible read-only TrueNAS Reader/MCP or a separately configured Google Drive mirror.
- Source-level file inspection is preferred; ZIP members and bounded chunks can be read on the server when Reader supports them.

**TrueNAS Reader, Cloud Sync and seven-day retention are separately deployed server-side services**; installing this DMG does not install or configure them automatically.

## Known limitations — important

- **The exact RC14 V8 graphical Install/Update and full end-to-end behavior have not been independently confirmed.** RC13 remains the accepted *internal* fallback reference; it is **not** publicly released here.
- **Apple notarization/stapling is not confirmed.** A signed package is not the same as a notarized package; macOS Gatekeeper may decline it. Do not bypass security controls automatically.
- **This artifact derives from a reference TrueNAS environment and includes reference-specific server/account assumptions.** There is **no validated universal NAS configuration wizard**, and it cannot be advertised as plug-and-play for arbitrary users or NAS models.
- Source-bearing installer distribution is deliberately owner-authorized **for this specific SHA only**; do not infer authorization to publish other private source, build logs, keys, configuration secrets or future variants.
- The 30-second/900-second retry fields in the clipboard are **instructions for a receiving assistant**, not a guaranteed built-in background timer.
