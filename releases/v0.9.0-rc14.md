## What this preview provides

The current macOS application supports Finder Quick Action batching, private SMB upload to a configured NAS, destination BYTES/SHA-256 verification and a clipboard handover for a compatible read-only Reader/MCP or Google Drive mirror. Embedded private Tailscale provides the alternative network path to SMB when separately configured. Reader, Drive sync and seven-day retention are independently deployed server-side components.

**This binary is a testing prerelease, not a finished generic installer.** The public sanitized package uses non-working/default-neutralized connection targets; the owner-specific NAS details were removed. There is no independently validated wizard for any SMB NAS. RC14 final graphical installation/Update E2E and Apple notarization are not confirmed. Do not bypass Gatekeeper automatically.
