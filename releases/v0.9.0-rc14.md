# RC14 V8 — public prerelease policy and verified artifact identity

The first official public macOS Intel prerelease must be a **privacy-sanitized and newly signed** build derived from ChatGPT Drop **0.9.0-rc14 V8**.

**The original RC14 V8 DMG is PRIVATE and must never be uploaded to public GitHub Releases.** It includes NAS/SMB account and Tailscale infrastructure defaults. Its historical checksum is **not** the checksum of the public artifact.

## Public publishing requirements

The publication procedure must remove the original owner's NAS address, SMB account/share, private Tailscale peer and target, hard-coded installer defaults and GUI strings; require explicit end-user storage configuration; audit every staged file; re-sign helper, bundled app, graphical installer and DMG with a valid Apple Developer ID; verify the new disk image and signatures; and create a draft release **before** publishing.

The draft GitHub asset must be downloaded back from GitHub and checked against its **new** byte count and SHA-256. Never label an altered or repackaged binary with the original hash.

[GitHub Releases](https://github.com/StefanAlMare/ChatGPT-TrueNAS/releases) is the authoritative place to establish whether a real, downloadable prerelease exists. **This document is not itself a software download.**

## License and limitations

Official binaries are **free for non-commercial use only**. Commercial/business use, redistribution, modification, OEM distribution, paid hosting, resale and reuse of author-owned code in another product require **prior written permission**. Third-party licenses and statutory rights remain intact.

Some Python implementation files may remain **readable** inside the sanitized DMG; this does **not** make the project open-source or license reuse. A Developer ID signature necessarily exposes the legal name of the signing certificate holder. No passwords, keys, personal files or private NAS addresses should be bundled.

**Do not claim RC14 complete runtime E2E acceptance, Apple notarization, native Apple Silicon/Windows/Ubuntu support or universal NAS setup.** The current implementation predates the generic installer/setup-wizard phase.

## Română

Primul pre-release public **RC14 V8** trebuie să fie reconstruit dintr-o copie a DMG-ului intern, **curățat de toate datele personale de NAS/SMB/Tailscale, resemnat și verificat cu hash nou**. DMG-ul original nu se publică.

Utilizarea necomercială este gratuită; utilizarea comercială și reutilizarea codului necesită acord scris. Pachetul RC14 nu conține încă un asistent universal de configurare NAS, iar instalarea finală/E2E și notarizarea nu sunt confirmate.
